I'm Franklyn Raymond, a Developer and UI/UX Specialist at Gabeweb. For the past few years I've worked across the whole product: researching users, shaping flows, designing interfaces and writing the code that brings them to life.

Because I both design and build, nothing gets lost between the first sketch and launch. I work on websites, web and mobile apps, and brand visuals for clients who want clean interfaces, solid code and real results.
